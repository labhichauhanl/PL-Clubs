# Premier League Clubs Website
A modern and responsive Premier League Clubs showcase website built using HTML5 and CSS3. This project recreates a football-themed interface inspired by the official Premier League style, featuring club cards, stadium information, sponsor sections, navigation bars, and interactive hover effects.

# Features
1. Stylish dark-themed football UI
2. Premier League club showcase cards
3. Stadium information table
4. Sticky navigation bar
5. Hover animations and gradient effects
6. Responsive layout structure
7. Sponsor and partner section\Multi-section footer navigation

# Technologies Used
1. HTML5
2. CSS3
3. Google Fonts
4. Flexbox Layout
5. CSS Hover Animations & Gradients
